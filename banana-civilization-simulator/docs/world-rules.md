# World Rules

## 陣營識別
- **蘑菇王國**：政治與民意核心，穩定度容易受事件影響。
- **庫巴軍團**：高軍事壓力，傾向掠奪與破壞。
- **耀西農業區**：食物與農業供應核心。
- **大金剛部落**：香蕉需求與武力交易核心。

## 資源說明
- `coins`：交易能力。
- `food`：人口與穩定的基礎。
- `wood`：建設與維護。
- `bananas`：關鍵戰略／經濟資源。
- `military`：衝突能力。

## 每回合固定事件模板
1. 庫巴破壞香蕉田（香蕉/食物下降、軍事壓力上升）
2. 耀西農業豐收（食物增加）
3. 大金剛要求香蕉進貢（香蕉轉移，可能換得短期和平）
4. 蘑菇王國民意下降（王國穩定度下降）
5. 玩家城鎮穩定度變化（隨機微幅上下）

## NPC 記憶與關係（MVP 簡化）
- 每個 NPC 保留最近 5 條事件記憶。
- 關係分數範圍 -100 ~ +100。
- 事件發生時，依事件標籤調整相關 NPC 關係。
