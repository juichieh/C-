# Banana Civilization Simulator (Private MVP)

> 文字 MUD / 文明模擬最小可行版本（MVP），僅採用原創文字內容，**不包含任何官方圖片、音樂或侵權素材**。

## 專案目標
將「蘑菇世界」風格世界觀轉化為可長期擴充的文字文明模擬：
- 派系外交與衝突
- 資源經濟（特別是香蕉經濟）
- NPC 記憶與關係狀態
- 世界事件日誌

## MVP 功能（目前版本）
- Terminal 執行的 **10 回合**世界模擬
- 四大陣營：
  - 蘑菇王國
  - 庫巴軍團
  - 耀西農業區
  - 大金剛部落
- 核心資源：`coins`, `food`, `wood`, `bananas`, `military`
- 每回合自動觸發事件池中的事件並更新世界狀態
- 每回合輸出日誌（含 emoji 與派系敘事）

## 快速開始
```bash
cd banana-civilization-simulator
python3 src/main.py
```

# 🍄 瑪利歐文明模擬遊戲 (MVP) 設計總結報告
本專案旨在將瑪利歐世界觀轉化為一款聚焦於國家治理、經濟發展、外交關係與 AI 驅動 NPC 系統的文字 MUD 模擬經營遊戲。玩家將扮演領主，在多個陣營間維持生存並應對挑戰。
## 🌍 核心陣營與世界背景
遊戲世界由多個具備獨特動機與特徵的政治實體構成：
| 陣營 | 主要居民 | 關鍵詞 | 核心特徵 |
|---|---|---|---|
| **蘑菇王國** | 蘑菇人、人類 | 穩定、行政、首都 | 由桃子公主統治，具備廣大民意支持。 |
| **庫巴軍團** | 龜族、栗寶寶等 | 軍事侵略、擴張 | 階層式結構，以征服王國為目標，資源來自掠奪。 |
| **耀西部落** | 耀西種族 | 農業、島嶼、同盟 | 擅長合作與農耕，以水果與蛋類貿易聞名。 |
| **大金剛勢力** | Kong 種族 | 熱帶、香蕉、戰士 | 擁有豐富自然資源與強壯戰士的自治部落。 |
## ⚙️ 核心遊戲系統
### 1. 內政與經濟管理
 * **地區管理**：玩家管理城鎮的人口、資源倉庫、建築槽位與幸福度。
 * **經濟與資源**：
   * **基礎資源**：硬幣、穀物、木材、石頭。
   * **特產資源**：火花星（士氣）、香蕉（Kong 族必需品）、耀西蛋等。
   * **維持機制**：大金剛勢力每回合需消耗香蕉，否則幸福度與軍隊士氣會下降。
 * **貿易與市場**：支持內部調配與外交貿易，物價受供需與戰爭事件影響。
### 2. AI NPC 記憶系統
NPC 不再只是機器人，而擁有三層次記憶與行為傾向：
 * **記憶機制**：記錄事件日誌、情緒強度、以及玩家的具體行為（如援助或背叛）。
 * **行為決策**：根據性格、記憶情緒與當前利益決定行動（例如是否接受交易或發動攻擊）。
 * **關係網絡**：好感度會隨互動調整，並可透過八卦網絡傳播。
### 3. 進階外交與獨立機制
 * **獨立機制**：若城鎮幸福度（<40）或忠誠度（<-50）過低，玩家可發起獨立公投脫離蘑菇王國。
 * **外交事件**：
   * **農業同盟**：當耀西與大金剛友好度 >50 時可觸發，增加產量並降低關稅。
   * **王室政策**：公主桃子的「徵稅令」或「慶典」會直接影響全球民意與 NPC 看法。
 * **破壞與重建**：庫巴突襲會摧毀農田，玩家需啟動災後重建任務以避免飢荒。
## 🔄 核心遊戲流程 (Gameplay Loop)
 1. **世界更新**：固定時間步進更新資源產出、人口與隨機事件。
 2. **資訊呈現**：玩家接收包含幸福度、庫存與外交消息的文字報告。
 3. **決策輸入**：玩家輸入文字指令（如 build farm 3 或 trade yoshi 50 bananas）。
 4. **NPC 回應與決議**：AI NPC 根據記憶解析玩家行動，解決事件效果。
 5. **歷史存檔**：將變動儲存至資料庫，並更新全球事件日誌供回顧。
